# Environment Variables by Platform

Where each variable lives. Never commit real values.

## Render (backend runtime)

Template: `backend/.env.prod_example`. Set in Render → Service → Environment.

| Variable | Example / how to get | Notes |
| --- | --- | --- |
| `ENV` | `production` | Set by `render.yaml`; enables prod safety checks |
| `DATABASE_URL` | Supabase Session pooler URL, `postgresql+psycopg://postgres.<ref>:<pw>@aws-0-<region>.pooler.supabase.com:5432/postgres?sslmode=require` | URL-encode the password |
| `JWT_SECRET` | `python -c "import secrets; print(secrets.token_urlsafe(48))"` | Auto-generated by `render.yaml` |
| `ACCESS_TOKEN_EXPIRE_MINUTES` | `480` | |
| `INITIAL_ADMIN_EMAIL` | your admin email | Seeds the first admin |
| `INITIAL_ADMIN_PASSWORD` | strong password | Not `changeme` / `password` in prod |
| `API_BASE_URL` | `https://<service>.onrender.com` | |
| `FRONTEND_URL` | `https://<project>.vercel.app` | |
| `ALLOWED_ORIGINS` | `https://<project>.vercel.app` | CORS; comma-separated, no trailing slash |
| `N8N_WEBHOOK_SECRET` | random string | Auto-generated by `render.yaml` |
| `SECRETS_ENCRYPTION_KEY` | `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"` | Losing it makes stored per-business OpenAI keys unreadable |

OpenAI keys are not env vars; the superadmin sets one per business in `/admin`.

## Vercel (frontend build/runtime)

Set in Vercel → Project → Settings → Environment Variables (Production). Fetched by `vercel pull`.

| Variable | Example | Notes |
| --- | --- | --- |
| `NEXT_PUBLIC_API_URL` | `https://<service>.onrender.com/api/v1` | Baked in at build time; redeploy after changing |
| `NEXT_PUBLIC_APP_URL` | `https://<project>.vercel.app` | |
| `NEXT_PUBLIC_ENV` | `production` | |

Do not set `DOCKER_BUILD` on Vercel.

## GitHub (Actions secrets)

Add under Settings → Environments → `prod` (and `dev` if used).

| Secret | Used by | Source |
| --- | --- | --- |
| `RENDER_SERVICE_ID` | `deploy-backend.yml` | `srv-…` in the Render service URL |
| `RENDER_API_KEY` | `deploy-backend.yml` | Render → Account Settings → API Keys |
| `VERCEL_TOKEN` | `deploy-frontend.yml` | vercel.com/account/tokens |
| `VERCEL_ORG_ID` | `deploy-frontend.yml` | `orgId` in `frontend/.vercel/project.json` |
| `VERCEL_PROJECT_ID` | `deploy-frontend.yml` | `projectId` in `frontend/.vercel/project.json` |
| `NEXT_PUBLIC_API_URL` | `deploy-frontend.yml` | Same value as on Vercel |

Runtime secrets (`DATABASE_URL`, `JWT_SECRET`, etc.) do not belong in GitHub.

## Supabase

No env vars to set. It supplies the `DATABASE_URL` (Project → Connect → Session pooler).
